@briwa.dev/sandbox

A fenced code block becomes a live, isolated iframe figure. Each figure gets its own disposable realm — srcdoc, sandbox="allow-scripts", no allow-same-origin — so it cannot reach the page around it.

  • figures — every block type, rendered from markdown
  • playground — edit markdown, watch the figures rebuild
  • editor — the authoring UI: widgets, slash commands, modals

These pages import the package by its public name; the aliases in vite.config.js point them at src/, so edits show up without a package rebuild.
